# ⛪ Planificador de Servicio – Iglesia

Este proyecto es una página web sencilla para ayudar a organizar los servicios de la iglesia.

Permite:
- Elegir un **rol** (director o músico)
- Seleccionar un **director**
- Ver el listado de **canciones y acordes**
- Usar la web desde cualquier celular o computadora

La página está publicada usando **GitHub Pages**.
